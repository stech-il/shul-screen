# אפליקציית ניהול מהטלפון

ניהול זמנים, הודעות והגדרות — **בלי** עיצוב מסך / בונה קנבס / מדיה / נוסח.

## שימוש מיידי (אתר / PWA)

פתחו:

`https://www.screensmart.co.il/#/manage`

1. הזינו מזהה מסך  
2. התחברו  
3. ערכו תוכן ופרסמו  

במצב זה מוסתרות הלשוניות: עיצוב, בונה מסך, מדיה, נוסח.

## מה כלול

- תוכן / זמני תפילה  
- הודעות  
- זמני היום  
- יארצייט  
- מצבים  
- שידור חי  
- הגדרות  
- משתמשים  
- תמיכה  
- היסטוריה  

## APK ניהול (אופציונלי)

בנייה עם מעטפת ניהול (פותחת ל־`/#/manage`):

```bash
npm run android:manage-sync
npm run android:open
```

מומלץ לשנות ב־`capacitor.config.ts` ל־`appId: il.screensmart.manage` ו־`appName: screensmart ניהול` לפני בניית APK נפרד מהקיוסק, כדי ששתי האפליקציות יוכלו להתקין זו לצד זו.

כרגע אפשר גם פשוט להוסיף את `/#/manage` למסך הבית של הטלפון (PWA / קיצור דרך).
